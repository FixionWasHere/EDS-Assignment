2) Write a Python program for following conditions.
 If n is single digit print square of it.
 If n is two digit print square root of it.
 If n is three digit print cube root of it:


import math
num = float(input("enter your number: "))
if 0<=num<=9:
    result = num*num
    print(f'{result}')

if 10<=num<=99:
    result = math.sqrt(num)
    print(f'{result}')

if 100<=num<=999:
    result = math.cbrt(num)
    print(f'{result}')

to age and also salary which is in rupees to salary in dollars using functions :

from datetime import datetime

def calculate_age(birth_year):
    current_year = datetime.now().year
    return current_year - birth_year

def converter(rupees):
    rate = 83
    return rupees/rate

birth_year = int(input("Enter  birth  year: "))
salary = float(input("Enter salary in rupees: "))

print("Age =",calculate_age(birth_year))
print("Salary in dollar: ",converter(salary))
